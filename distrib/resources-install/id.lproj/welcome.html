Sebelum Memulai

Program ini menginstal Sister HL-2030, driver asli untuk printer Brother HL-2030 series.

@HALFTONE_NOTE@

Sebelum melanjutkan:

  1. Hubungkan printer ke Mac ini dengan kabel USB dan nyalakan.
  2. Pastikan driver Brother tidak terinstal. Jika Anda telah menginstalnya di komputer ini, jalankan UninstallBrotherDrivers.pkg untuk menghapusnya.

Klik Lanjutkan untuk meneruskan.
