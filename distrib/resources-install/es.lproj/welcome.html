Antes de empezar

Esto instala Sister HL-2030, un controlador nativo para la impresora Brother HL-2030 series.

Antes de continuar:

  1. Conecta la impresora a este Mac con un cable USB y enciéndela.
  2. Asegúrate de que los controladores oficiales de Brother estén desinstalados. Si todavía están instalados, cierra este instalador, ejecuta primero UninstallBrotherDrivers.pkg y luego vuelve a ejecutar este instalador.

Haz clic en Continuar para proseguir.
